# Solution specifications

The specification workflow authors and freezes the solution here. Start from `.rdd/templates/specification.md`; link each obligation and scenario through `.rdd/spec.json`.

This initial directory contains no accepted Todo specification. Architecture, modules, Rust UI framework, embedded Turso behavior, public/local interfaces, protocols and test commands must be derived from the supplied requirements.

Keep one owner for each normative fact. Resolve questions during specification. Downstream ambiguity returns to specification rather than being guessed during implementation.
