# Generated contract outputs

`gen/rust/` is created only after successful Buf/Rust qualification. Leave it absent or empty before first generation; the driver refuses to replace an unowned nonempty tree.

Generated message types and local unary service traits, Cargo manifests/lockfiles and generation metadata are checked in and frozen as specification outputs. Do not hand-edit generated Rust or reclassify contract changes as implementation tasks.

Build artifacts go to ignored runtime/target locations, not this tracked source tree.
