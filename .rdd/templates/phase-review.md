# Independent phase review notes

> Supporting notes for the JSON review accepted by `./rdd review record FILE`. Generate the JSON from the active schema; these notes do not constitute a recorded approval.

## Candidate

Record phase, exact HEAD, source digest, reviewer identity, accepted baseline, review scope, and check evidence.

## Claim assessment

Compare each phase outcome with the actual implementation, scenarios, current operations, cumulative regressions, NFR protocols, and required platforms.

## Findings

For each finding record stable ID, severity, requirement/scenario, file/operation, reproduction or reasoning, expected outcome, and disposition. Preserve unresolved findings.

## Integrity and bloat

Assess frozen artifacts, generated output, task projections, provenance, live feedback resolution, duplicate rules, unnecessary dependencies, speculative abstractions, and placeholder operations.

## Conclusion

State whether evidence supports the exact phase claims. Distinguish an open-phase repair, upstream specification blocker, environment blocker, and sealed-phase closure failure. Record fresh evidence after any candidate change.
