# Worker packet

> Fill from controller state and frozen artifacts. This packet authorizes only the assigned scope; it cannot override requirements, contracts, or repository policy.

## Identity

Record active run, current branch/commit/source digest, canonical worker role, controller-provided requested runtime/profile identity, task IDs, phase, category, sorted vertical membership, primary/secondary work-site IDs, and lease/worktree locator. Keep actual observed session/events separate from requested settings; do not label the backend model verified without evidence.

## Bounded context

Link only relevant requirement, specification, fully qualified operation/contract, scenario, and skill sections. Include relevant accepted S1 inventory entries, distinct module owner IDs, frozen public exports and binding identities. Name each consumer/provider operation, type import or composition export and its applicable proof obligations without copying schemas. Identify authoritative sources and exclude superseded discussion.

## Work and ownership

Use the frozen full primary packet. State the objective, bounded instructions, permitted write paths and every local work site, required inputs with their verified producers and use timing, outputs, shared-file integration owner, and acceptance. Include approved reuse rationale for additions. Do not delegate unresolved grooming or design questions.

## Evidence

Name required check IDs and TDD expectations. State how to report changed files, commit, check receipts, unresolved issues, and review observations to the orchestrator.

## Stop conditions

Record a critical harness regression and stop for a frozen specification/planning defect. Preserve origin/detection stage, affected IDs, exact candidate and evidence. Also stop for stale source digest, overlapping ownership, missing required capability, or sealed-phase invalidation. Preserve a checkpoint and exact evidence; do not edit the ledger or fabricate a passing result.
