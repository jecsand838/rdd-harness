# Canonical requirements

`requirements.md` is the supplied Todo requirements document, preserved byte for byte. It contains both functional and non-functional requirements plus shared data rules and acceptance criteria. Its original draft status is preserved; the specification workflow resolves and confirms direction with the developer before accepting a solution.

Change this file only under the developer's requirements direction. Commit a changed requirement before starting `./rdd workflow specification --mode amend`. Stable requirement IDs support impact analysis. Do not edit solution specs as a substitute for changing the problem definition.
