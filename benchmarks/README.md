# Future application benchmarks

The Todo performance requirements define the measurable obligations. Specification freezes datasets, reference hardware, timing boundaries, sampling, warmup, independent error detection and pass thresholds. Preparation then creates explicit workload/evaluator tasks. No application performance result is claimed by this boilerplate.

See `docs/harness/evidence-guide.md` for the executable raw-sample format, nearest-rank percentiles, host qualification and imported evidence rules. A benchmark command's exit code alone cannot pass a threshold. Hosted CI records reference-host checks as pending external evidence; phase/project gates require their actual qualified results.
