# Repository-local RDD skills

Use the three primary workflow skills in order. Load language/framework/development/planning skills only when relevant to the current bounded task; linked references contain worked examples and official sources.

These are portable repository skills supplied with this harness. They are not a personal global installation. The developer may refine them before specification freeze; implementation tasks cannot rewrite their own frozen guidance or acceptance policy.

For maintenance of the harness itself, use [rdd-harness-research](rdd-harness-research/SKILL.md) for a grounded brief, [rdd-harness-audit](rdd-harness-audit/SKILL.md) for read-only inspection of all three workflows, [rdd-harness-reductive-repair-diff](rdd-harness-reductive-repair-diff/SKILL.md) for a complete isolated proposal, and [rdd-harness-reductive-repair](rdd-harness-reductive-repair/SKILL.md) for an authorized, independently reviewed local repair. Each future repair's entire patch, including tests/docs, must reduce aggregate text lines while preserving behavior and checks. These skills do not bypass frozen run policy or initialize a run when none exists; publication needs separate session authorization.
